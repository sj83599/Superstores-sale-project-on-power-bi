# Superstores-sale-project-on-power-bi
Built an interactive Superstore Sales Dashboard analyzing 9K+ transactions.
📊 Key Features:
✅ Sales trend analysis (2014-2017)
✅ Profit vs Sales correlation
✅ Top 10 product performance
✅ Regional & category breakdown
✅ Interactive filters

💡 Key Insights:
- Technology drives 36% of revenue
- Q4 shows 250% growth vs Q1
- West region leads with $730K sales
- Identified loss-making high-sales products

🛠️ Tools: Power BI | Power Query | DAX

This project helped me understand data storytelling and business intelligence fundamentals.
